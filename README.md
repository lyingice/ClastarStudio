# 像素工坊 · PIXEL WORKSHOP

这是 `OutPuts/studio_shell.html` v0.4.2 的**一比一搬运基线**，并在基线上新增了
「一键换色」工具、Blockbench 风格侧栏、编辑器内部左右面板、中央参照画布、多选资源包导出、
复合整图拆分、实体装备纹理、智能 ZIP 导入、仓库素材选择器、变种工坊和快捷键中心；当前版本 **v0.12.0**。
原有外观、交互、文案、数据键、PWA 和六个内嵌编辑器都保留，没有换成另一套 UI。

## 运行

```bash
python serve.py
```

打开 http://127.0.0.1:8766/ 。

手机 / 局域网调试：

```bash
HOST=0.0.0.0 PORT=8766 python serve.py
```

## 侧栏

参考了 Blockbench 的 `Panel` / `Interface.toggleSidebar` / `ResizeLine` /
移动端 `panel_selector_bar` 的实现，并按老壳的操作习惯做了简化：

- **左侧面板组**：工作区 / 工具 / 库三组，组头可折叠，工作区数量、回收站数量直接显示
- **宽度拖拽**：拖动左右栏边缘调整宽度，接近默认值会自动吸附，双击恢复默认
- **布局持久化**：左右栏宽度、折叠状态、左右栏是否收起、手机当前面板都写入
  `pixelWorkshop_sidebar_v1`
- **右侧快捷栏**：快捷操作（新建内容 / 新建大类别 / 导入 PNG / 一键换色）、当前工作区摘要、
  最近打开 4 项
- **快捷键**：`Ctrl+B` 收起/展开左侧栏，`Ctrl+Shift+B` 收起/展开右侧快捷栏
- **手机端**：底部条改为「工作区 / 首页 / 快捷 / 设置」；左侧抽屉用
  工作区 / 工具 / 库三个面板切换，右侧抽屉是快捷操作与最近打开
- 没有照搬 Blockbench 的面板拖拽换栏和浮动面板，避免破坏原壳的轻量操作

## 编辑器内部左右侧栏

绘画时不再显示额外的外壳右栏，顶部工具栏就是唯一的快捷工具区。交互集中在动画编辑器
自己的左右面板里：

- **左栏**：画布 / 动画、帧、颜色、调色板、播放设置
- **右栏**：图层、一键光源·拓展、参考图 / 仓库、彩色渐变、.mcmeta、导出、作品仓库
- **面板头**：`⠿` 拖动面板可以换到另一栏或调整顺序；点标题 / 箭头折叠；`⧉` 弹出浮窗；`📌` 固定浮窗位置
- **面板跳转**：左右栏顶部都有「跳转面板」下拉，选中任意面板会展开并滚动到它
- **栏宽拖拽**：拖动左右栏边缘可把宽度调到 240–480px，双击恢复默认；宽度会记住
- **布局记忆**：面板左右归属、顺序、折叠、浮窗位置保存在 `animStudioPanels_v2`；
  栏宽保存在 `animStudioSideWidths_v1`
- 手机端仍使用编辑器自己的左 / 右抽屉和全屏按钮，不额外占用画布

## 中央参照画布

纹理 / 动画编辑器的主画布旁新增「参照」按钮，展开后直接并排显示一张自定义参照画布：

- 右侧「参考图 → 导入」或参照画布自己的「导入参考图」都能载入；也支持直接把图片拖到参照画布
- 导入后自动展开，主画布和参照画布并排显示，方便逐像素对比
- **点击取色**：点参照画布上的像素，立即把主画笔色设为该颜色，颜色面板和最近颜色同步更新
- 拖动平移、滚轮缩放、双击适应；收起后主画布恢复原尺寸
- 参照图仓库、参考调色盘仍然保留；原来右侧 160px 的小预览已隐藏，避免和中央画布重复
- 参照画布和原参考面板底色改为中性灰 `#242424`，不再是暗蓝；主编辑画布保持 `#232323`
- 动画编辑器内部、颜色面板和取色颜色保持双向同步

## 多选与资源包 ZIP

- 首页内容栏「多选」进入选择模式；点卡片切换选中，支持文件夹（导出时展开子项）
- 选择栏：已选数量、全选当前视图、清空、导出资源包、完成
- 手机端长按卡片也能打开右键菜单（打开 / 换色 / 加入多选 / 重命名 / 复制 / 删除）
- 导出对话框：资源包名称、命名空间、目标版本（1.21.9/1.21.8/1.21.5/1.21.4）、普通纹理归类、旧版盔甲路径
- 自动写入 `pack.mcmeta`、`pack.png`；动画自动带 `.png.mcmeta`
- 路径规则：
  - 普通纹理 → `assets/<ns>/textures/item|block/<name>.png`
  - 方块 → 每个材质一张，单材质时用方块名
  - 复合纹理 → 5 张来源 + 1 张 `_composite.png`（128×128）
  - 人形盔甲 → `entity/equipment/humanoid` + `humanoid_leggings`，可选旧版 `models/armor`
  - 狼铠 / 马铠 / 鹦鹉螺铠 / 恶魂挽具 / 鞘翅 → 对应 `entity/equipment/*` 路径
  - ZIP 导入的作品会保留原始 `assets/...` 路径和 `.mcmeta`

## 复合纹理整图

复合方块工坊顶部新增：

- **导入整图**：选择外部的 128×128 复合整图，按 Sedna 8×8 连接图**反向拆成 5 张 16×16 来源**，
  自动填回 1–5 号连接纹理并重绘 3D 预览
- **导出整图**：把当前拼接结果导出为 128×128 PNG
- 仓库素材选择器里的「复合整图」也能直接送进这个拆分流程
- 资源包导出会额外带上 5 张来源和整图，方便在外部工具继续编辑

## 更多实体纹理

实体工坊顶部新增「类型」选择，目前支持：

| 类型 | 尺寸 | 资源路径 |
| --- | --- | --- |
| 人形盔甲 | 64×32 × 2 层 | `entity/equipment/humanoid` / `humanoid_leggings` |
| 狼铠 | 64×32 | `entity/equipment/wolf_body` |
| 马铠 | 64×64 | `entity/equipment/horse_body` |
| 鹦鹉螺铠 | 128×128 | `entity/equipment/nautilus_body`（26.1+） |
| 快乐恶魂挽具 | 128×128 | `entity/equipment/happy_ghast_body` |
| 鞘翅 | 64×32 | `entity/equipment/wings` |

- 人形盔甲继续使用双层 3D 人台；其它类型使用整张纹理 + 16px 网格 + 参考分区
- 导入时按当前类型校验尺寸；绘画标签会按实际宽高打开，不再固定 64×32
- 新建内容 → 实体，可直接选类型；实体编辑器里也能切换类型
- 智能 ZIP 导入会自动识别人形 / 狼 / 马 / 鹦鹉螺 / 恶魂 / 鞘翅纹理，合并成对应实体卡片

## 智能 ZIP 导入

快捷操作「导入资源包 ZIP」，或把 `.zip` 直接拖进窗口：

- 解析 `assets/<namespace>/textures/...`，自动新建以压缩包命名的工作区
- 自动分类：方块纹理 / 物品纹理 / 实体装备 / 实体纹理 / 盔甲 / 界面 / 粒子 / 画 / 环境 / 字体 / 杂项
- 按子目录自动建文件夹；保留原始 `packPath` 和动画 `.mcmeta`
- 自动识别人形盔甲双层、狼铠、马铠、鹦鹉螺铠、恶魂挽具、鞘翅，并合并成实体卡
- 跳过 `pack.png`、`__MACOSX` 和隐藏文件；ZIP 支持 Store / Deflate

## 仓库素材选择器

所有内嵌编辑器的工具栏都新增「仓库素材」：

- 纹理 / 动画 → 按当前导入方式作为图层或条带导入
- 自定义纹理 → 缩放到当前画布
- 方块 → 导入当前选中材质
- 复合 → 16×16 来源导入选中面；128×128 或「复合整图」自动拆 5 面
- 实体 → 按当前类型校验尺寸后导入选中层
- 参考图面板新增「仓库」按钮，可直接把库内作品设为参考图

选择器支持按作品名 / 工作区 / 类别 / 类型搜索，显示预览、来源和素材类型。

## 工具模块化 / 官方扩展

- 新增 `PWExtensions` 工具注册表：工具页、编辑器拓展统一描述、启停、持久化
- 设置 → 工具与扩展可开关：
  - 工具页：色彩拓展、一键换色、变种工坊
  - 编辑器拓展：一键光源、彩色渐变叠加
- 关闭后左侧工具栏、右侧快捷栏入口同步隐藏；编辑器内对应面板通过 postMessage 同步隐藏
- 官方内置工具也走同一套注册表；`PWExtensions.register({...})` 已预留外部 JS 插件注册接口
- 扩展支持 `open / onEnable / onDisable` 生命周期，后续可接外部插件导入
- 状态保存在 `pixelWorkshop_extensions_v1`

外部插件后续可以通过同一个入口注册：

```js
PWExtensions.register({
  id: 'my-tool',
  name: '我的工具',
  kind: 'tool',          // tool = 工具页；editor = 编辑器面板
  icon: 'box',
  version: '1.0.0',
  open(){ /* 打开工具页 */ },
  onEnable(){ /* 可选 */ },
  onDisable(){ /* 可选 */ }
});
```

## 变种工坊

灰度/明度映射材质色阶，批量产出同结构变种：

- 母版来源：当前仓库的主纹理、动画条带、方块材质、复合来源、实体盔甲层
- 14 套内置色阶：铁、钢、铜、青铜、金、银、紫水晶、绿宝石、红宝石、青金石、木头、黑曜石、冰、剧毒
- 自定义色阶：编辑 4 段颜色、命名并保存，支持删除和恢复预设
- 处理选项：自动拉伸明度、描边保护、保留纯黑描边、反转明暗、对比度、Gamma
- 矩阵预览：母版 × 色阶，点击格子可切换是否导出
- 导出：PNG ZIP（平铺或按色阶分文件夹）+ `variants.json` 清单
- 保存到仓库：直接生成「变种生成」类别下的变种卡片，可继续多选导出资源包
- 命名模板：`{name}_{ramp}` / `{name}_{rampName}`
- 入口：工具 → 变种工坊；卡片右键 → 变种工坊

## 快捷键

快捷键没有塞进设置弹窗，而是独立的「快捷键中心」：

- 设置 → 快捷键：显示动作数、自定义数、冲突数，点「管理」打开中心
- 快捷键中心：搜索、分组过滤、录制按键、单项/全部恢复默认、导出/导入 JSON
- 冲突检测：同一上下文重复键会直接拦截；`Ctrl+W`、`Ctrl+T` 等浏览器保留键会提示不可用
- `?` 打开快捷键速查卡，卡内可直接进入管理页
- 默认动作：全局 4 个（设置、速查、左右栏），编辑器工具 4 个（画笔/橡皮/油漆桶/吸管），动画 3 个，编辑 2 个
- 编辑器工具按钮会显示单键徽标（如 `B`），撤销/重做等完整组合显示在 tooltip
- 改键后动画编辑器和自定义纹理编辑器实时同步；自定义纹理编辑器补齐了工具键处理
- 状态保存在 `pixelWorkshop_shortcuts_v1`
- 外部扩展注册时可附带 `shortcuts`，或调用 `PWShortcuts.registerAction({...})`，由快捷键中心统一做冲突检测

## 一键换色

来源：Blockbench 插件 `color_replacer.js` 1.2.0 的精确换色 / 聚类换色逻辑。

Clastar 版做了菜鸟化和现代化改造：

- **三步流程**：选纹理 → 自动配色 → 应用并保存
- **菜鸟化**：默认自动读取颜色并生成主题配色；点预设即可整图换色；色卡按明暗自动套用；
  逐色微调、清空目标色、全部预设、实时并排预览、撤销上次应用
- **现代化**：Ore UI 深色布局、原图/结果并排、像素放大预览、原生取色器、
  容差和聚类数量、导出 PNG、手机端单列布局
- **接入位置**：
  - 左侧「工具 → 一键换色」
  - 纹理 / 动画 / 自定义纹理 / 方块 / 复合 / 盔甲编辑器的顶栏「一键换色」
  - 卡片右键菜单「一键换色」
- **可处理资产**：主纹理、动画条带、自定义纹理、方块材质、复合纹理来源、盔甲两层纹理
- **写回**：主纹理/动画会同步更新缩略图；方块 / 复合 / 盔甲会用隐藏编辑器重新生成 3D 缩略图

`src-composite` / `src-entity` / `src-ctex` 的 base64 内容，解码后与原内嵌文档一致。
