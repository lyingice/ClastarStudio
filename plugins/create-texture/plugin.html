1 · 读取机械动力

支持 Create 6.x 的 assets/create 资源结构
本地内容包怎么放？
把 Create 模组 jar 放进 local/inbox/，双击项目根目录的 准备本地素材.bat。
扩展会自动读取生成的 local/create-pack.zip；GitHub 版只包含插件，不附带 Create 资产。

2 · 方块族 0

已选 0
先载入 Create 资源包。
没有选中的方块族 载入 Create jar 后，左侧会出现按 blockstate/model 归类的方块族。
选择后查看纹理槽、状态和连接纹理图集。

3 · 导入到仓库

勾选方块族后导入；每个方块族会成为一张 Create 卡片。

4 · 材质变种包

实验性：默认关闭。机械动力变种暂不成熟，需要时再手动勾选色阶。

勾选方块族与色阶后导出；每个色阶一个资源包，ZIP 内按 packs/<色阶>/ 分目录。

适配说明

支持：多纹理槽、blockstate 状态族、32/64/128 的 CT 连接图集、动画和滚动纹理标记。

CT 图集按 16px 小格识别；导入后保留原始 packPath 和方块族元数据。

支持 cuboid 3D 预览、OBJ / MTL 只读几何预览与静态 / 动态元素拆分；复杂 CTModel / 方块实体仍只做图集预览。
