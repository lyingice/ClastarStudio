常规方块归档 0

非动态楼梯、台阶、窗格、梯子、脚手架、装饰矿石/石材等常规方块已自动过滤出机械列表，归属到「素材库」。

扫描后自动识别常规装饰方块纹理。

适配说明

左侧以直观元件网格展示机械动力核心动力、物流、流体与列车方块；悬停可查看中英文名称与状态。

原版引用纹理（如木板、圆木、铁栏杆）自动衔接本地原版资源包渲染，避免 3D 预览马赛克。

支持 cuboid 3D、OBJ / MTL 只读几何预览与动态角度调试，以及 32/64/128 CT 图集识别。
